# Rezka Local Base — формат базы данных

Файл `rezka_database.json` — это массив объектов. Каждый объект — одна единица контента (фильм, сериал, мультфильм или аниме).

Ссылки на стримы **не хранятся**. Аддон получает их с rezka.ag в момент воспроизведения, поэтому они всегда свежие.

---

## Поля

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `title` | string | ✓ | Название, отображается в Kodi |
| `type` | string | ✓ | Категория: `фильмы`, `сериалы`, `мультфильмы`, `аниме` |
| `url` | string | ✓ | Прямая ссылка на страницу фильма/сериала на rezka.ag |
| `translators` | array | ✓ | Список озвучек (строки) — только для отображения в меню |
| `seasons` | object | Только для сериалов | Словарь `"номер_сезона": количество_серий` |

---

## Фильм (`type: "фильмы"`)

```json
{
  "title": "Джой (2015)",
  "type": "фильмы",
  "url": "https://rezka.ag/films/drama/12345-joy-2015.html",
  "translators": ["MGG", "Оригинал (+субтитры)", "Дублированный"]
}
```

**Навигация в Kodi:**  
`Фильмы → Джой (2015) → Выбор озвучки → Выбор качества → Воспроизведение`

---

## Мультфильм (`type: "мультфильмы"`)

```json
{

  "url": "https://rezka.ag/cartoons/family/9876-zootopia-2016.html",

```

## Сериал (`type: "сериалы"`)

```json
{
  "title": "Во все тяжкие (2008)",
  "type": "сериалы",
  "url": "https://rezka.ag/series/crime/1234-breaking-bad-2008.html",
  "translators": ["LostFilm", "NewStudio", "Оригинал"],
  "seasons": {
    "1": 7,
    "2": 13,
    "3": 13,
    "4": 13,
    "5": 16
  }
}
```

**Навигация в Kodi:**  
`Сериалы → Во все тяжкие → Выбор озвучки → Сезон X → Серия Y → Выбор качества → Воспроизведение`

## Мультсериал (мультфильм с сезонами)

`type: "мультфильмы"` + поле `seasons` — работает так же, как сериалы.

```json
{
  "title": "Гравити Фолз (2012)",
  "type": "мультфильмы",
  "url": "https://rezka.ag/cartoons/adventures/5555-gravity-falls-2012.html",
  "translators": ["Дублированный", "Оригинал"],
  "seasons": {
    "1": 20,
    "2": 20
  }
}
```

## Как найти URL на rezka.ag

1. Зайди на rezka.ag и найди нужный контент
2. Скопируй URL страницы из адресной строки браузера
3. Вставь в поле `"url"` — это единственное что нужно

**Пример:** `https://rezka.ag/films/drama/1234-film-2020.html`

---

## Как узнать озвучки

Зайди на страницу контента на rezka.ag. Озвучки — это кнопки под плеером. Скопируй названия точно как написано на кнопках. Если аддон не нашёл точное совпадение, он попробует найти ближайшее по подстроке.

Поле `translators` влияет только на то, **что показывается в меню**. Если ты укажешь не все озвучки — страшного ничего нет, работающие останутся. Если напишешь неточно — аддон попробует найти совпадение на странице.

---

## Как узнать количество серий

Зайди на страницу сериала на rezka.ag. Под плеером есть список сезонов и серий. Посчитай серии в каждом сезоне и запиши в `seasons`.

---

## Формат базы (структура файла)

```json
[
  { ...фильм... },
  { ...сериал... },
  { ...аниме... }
]
```

Просто массив объектов. Порядок не важен — сортировка идёт по `type`.

---

## Совместимость

Старые записи с хранимыми ссылками (формат `"translators": {"MGG": {"720p": "https://..."}}`) продолжают работать без изменений, пока токены в ссылках не истекут. После истечения их нужно переписать в новый формат.
